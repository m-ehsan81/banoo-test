# Banoo Perfume — React version

A responsive React + Vite implementation of the Banoo Perfume website.

## Requirements
- Node.js 18 or newer
- npm

## Run locally
```bash
npm install
npm run dev
```
Open the local URL printed by Vite (usually http://localhost:5173).

## Production build
```bash
npm run build
npm run preview
```

## Project structure
- `src/main.jsx` — React app, routes, navigation, splash screen, page sections, contact/footer.
- `src/style.css` — responsive styling and visual theme.
- `public/assets/` — supplied brand and campaign images.

Routes:
- `/` — Home / landing page
- `/products` — Products and services
- `/about` — About Banoo

The address and Instagram handle are placeholders and can be changed in `src/main.jsx`.
